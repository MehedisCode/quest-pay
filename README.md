# 🧠 Quest Pay

Quest Pay is a **question–answer platform** where users can ask questions and optionally attach a **small payment** as a reward for the best answer. It’s designed to encourage quality contributions while allowing developers, students, and experts to share knowledge and earn rewards.

## 🚀 Features

- 💬 **Ask & Answer Questions** — Users can post questions and receive answers from others.
- 💰 **Payment Integration** — Attach small payments for premium questions or answers.
- 🧑‍💻 **User Authentication** — Secure login and registration for users.
- 🎨 **Modern UI/UX** — Clean and responsive design built with Tailwind CSS.
- ⚡ **Fast API Backend** — RESTful API powered by Express.js.
- 🧩 **Modular Architecture** — Well-structured frontend and backend code for scalability.

---

## 🛠️ Tech Stack

### Frontend
- React.js
- Tailwind CSS
- Axios (for API communication)
- React Router DOM

### Backend
- Express.js
- MongoDB (with Mongoose ODM)
- dotenv (for environment variables)
- cors, body-parser, etc.

### Example .env File
For the backend:
- PORT=5000
- MONGODB_URI=mongodb://127.0.0.1:27017/quest-pay
- JWT_SECRET=your_secret_key
